Harbor Hub allows for publishing & sharing datasets and tasks. Think of Harbor Hub like HuggingFace or PyPI for RL environments.

## Publishing

To publish a task or dataset to Harbor Hub, run

```bash
harbor publish "<path/to/task>" # or path/to/dataset
```

You can also tag uploads using the `--tag` flag.

There are two ways to publish a dataset:

- `harbor publish ./dataset.toml` uses only the listed tasks, uploading missing local/Git versions and reusing accessible Hub versions.
- `harbor publish ./dataset-directory` uploads child tasks in that directory before publishing the dataset.

Use `--no-tasks` to skip dataset task uploads; all referenced versions must already be accessible on Hub.

## Visibility

By default, published tasks and datasets are private. You can make them public by using the `--public` flag.

```bash
harbor publish "<path/to/task>" --public # or dataset
```

Making a dataset public cascades to all tasks contained in any dataset version.

See [Sharing](/harbor-hub/sharing) for instructions on sharing published content.
